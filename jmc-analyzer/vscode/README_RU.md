# JMC Analyzer

> [!NOTE]
> Английская версия доступна в [README.md](README.md).

VS Code-расширение и языковой сервер (LSP) для языка JustCode (`.jc`) из компилятора [JMCC](https://github.com/jmcc-reborn/jmcc).

Поддерживает как английский (Modern), так и русский (Alternate) синтаксис JustCode (`while`/`for`, лямбды, `match`, `try`/`catch`, классы, интерфейсы, `export`, метки циклов, русские ключевые слова и типы).

## Возможности

### 1. Подсветка синтаксиса
- Точная TextMate-грамматика для ключевых слов, типов, действий JustMC, операторов и строк (с интерполяцией `$var` и `${expr}`).
- Полная поддержка русского синтаксиса (`функция`, `класс`, `пусть`, `перем`, `если`, `выбор`, `не`, `и`, `или`, `в`, `как` и др.).
- Семантическая подсветка (Semantic Tokens) по протоколу LSP в UTF-16 code units с корректным позиционированием для кириллицы.

### 2. Языковой сервер (LSP)
Встроенный Language Server предоставляет возможности IDE:
- **Диагностика на лету:** проверка синтаксиса, типов и семантики при вводе с предупреждениями (например, о нерекомендуемом `elif`) и локализацией сообщений (RU/EN).
- **Автоинференс типов и подсказки параметров (Inlay Hints):** отображение выведенных типов для нетипизированных переменных (`: текст`, `: число`, `: массив<текст>` для русского кода и `: text`, `: number` для английского), а также имен аргументов при вызове действий, функций и конструкторов.
- **Информация при наведении (Hover):** сигнатуры, выведенные типы, аннотации областей видимости переменных, псевдонимы и двуязычные комментарии документации (`/// RU:` / `/// EN:`).
- **Переход к определению (Go to Definition):** навигация к классам, интерфейсам, перечислениям, вариантам `enum`, функциям, методам и локальным переменным.
- **Поиск ссылок (References) и подсветка совпадений (Document Highlight).**
- **Переименование символов (Rename)** с безопасным обновлением всех вхождений.
- **Символы документа и воркспейса (Document / Workspace Symbols)** с поддержкой иерархии классов и методов.
- **Автодополнение (IntelliSense/Completion)** для действий, свойств, методов и глобальных символов.
- **Подсказки сигнатур (Signature Help)** при вызове действий и методов.
- **Форматирование кода (Document Formatting)** через встроенный форматтер компилятора.

## Сборка и установка

Расширение собирается вместе с крейтом `jmc-analyzer`:

```shell
cargo run -p jmc-analyzer -- pack
```

Собранный `.vsix` размещается в `jmc-analyzer/out/jmc-analyzer-<версия>.vsix`. Установка в VS Code:

```shell
code --install-extension jmc-analyzer/out/jmc-analyzer-0.1.0.vsix
```
