# Будущий language server

> [!NOTE]
> Английская версия доступна в [README.md](README.md).

Клиент VS Code запускает `jmc-analyzer lsp` через stdio, когда параметр `jmc.analyzer.enableLsp` равен `true`. Реализация находится в `jmc-analyzer/src/lsp/` (фича `lsp`). Эта директория зарезервирована для дополнительных ассетов сервера, которые могут понадобиться клиенту позже; она пока не включается в `.vsix`.
